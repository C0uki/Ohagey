# 0009: モデルのライセンス(CC-BY-SA 4.0)への対応

## 事実確認
`zenz-v3.1-small-gguf`(Miwa Keita/三輪氏)は**CC-BY-SA 4.0**というライセンスです。これは
AzooKeyKanaKanjiConverter・azooKey・SampleIME・おはぎー自身のコードが採用しているMIT
ライセンスとは異なる、継承ライセンス(コピーレフト)です。

## 決定事項
モデルを、おはぎー自体のコードベースとは切り離された「別ライセンスの資産」として扱います。

- 本リポジトリには一切コミットしない
- インストール時に単体ファイルとしてダウンロードする(決定0008を参照)
- 設定アプリの「このソフトウェアについて」画面に、作者名・ライセンス名・モデルページへの
  リンクを帰属表示として掲載する
- おはぎー自体のソースコードはMITのまま。CC-BY-SA 4.0の義務が及ぶのはモデルファイル自体
  のみ

## 判断の根拠
`unok/myime`やAndroidアプリ「Sumire」も、モデルを自分たちのコードライセンスに組み込まず、
外部の別ライセンス資産として扱っています。モデルを静的リンク・同梱するのではなく実行時に
取得する設計(決定0008)であることも、この切り分けを技術的にも法的にもクリーンにしています。

## 帰属表示の文言(設定アプリ「このソフトウェアについて」画面)

> (CC-BY-SA 4.0ライセンス)を使用しています。

## 追記(2026-08-04)— base 言語モデルにはライセンスの記載が無い

決定 0034 の個人化には、zenz の重みとは**別に** n-gram の base 言語モデルが要る。
これをインストーラで取得することにした(決定 0034 の 2026-08-04 追記)ため、
0009 の対象が1件増える。**ただし、この1件は 0009 の枠組みに素直には収まらない。**

### 事実確認

`Miwa-Keita/base_n5_lm`(4ファイル・42.6MB)は **ライセンスを一切明示していない**。
2026-08-04 に確認した:

- モデルカードに license フィールドが無い
- license タグが無い
- LICENSE ファイルが無い(リポジトリのファイルは `.gitattributes` と `lm_*.marisa` 4件のみ)

`zenz-v3.1-small-gguf` が CC-BY-SA 4.0 を**明示している**のとは対照的である。

### これが 0009 の前提を外す点

0009 は「別ライセンスの資産として扱い、帰属表示を掲げる」という形で解いた。
**ライセンスが無い場合、掲げるべき条項が存在しない。** 「ライセンス未記載」は
「自由に使える」ではなく、既定では**著作権者の許諾が無い状態**である。

### 取る立場

**再配布はしない。** インストーラは配布元の URL をユーザーの端末から叩くだけで、
ファイルはおはぎーの成果物に含まれない(決定 0008 と同じ形)。これは
「作者のリポジトリからユーザーが取得する」ことの自動化であり、
おはぎーが複製を頒布する行為ではない。

**存在は隠さない。** 設定アプリの「このソフトウェアについて」に、モデル名・配布元・
**ライセンスの記載が無いこと**を明記した。掲げる条項が無いからこそ、
何が端末に置かれ、どこから来たのかは見えているべきである。

### 未解決 — 作者への確認は**していない**

**これは暫定の立場である。** 確実にするには作者にライセンスの明示を依頼するのが筋だが、
外部への働きかけなので**指示が無い限り行わない**(決定 0034 の `_c_bc` 公開依頼と同じ扱い)。

- [ ] 明示されない場合、個人化の既定を「base 無しなら適用しない」に倒すか、
      base LM を自前で学習する(決定 0034 の案3)かを決める
